# Overlay opens the full catalog; only `/` search

The Bundesrecht pane fills the body (not a floating box) and shows the entire cached index as soon as it opens. Titles wrap onto following rows so the full name stays visible. `/` filters by shortcut, slug, or title; Esc restores the full list. A letter filter (`f` then A–Z) was dropped so `hjkl` stay unambiguous and the query can live in the pane instead of a second browse mode. Letter browse can return later if the full list is too large to scan.
